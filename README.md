# YouTube Clone

Static HTML and CSS layout of a YouTube home page, from February 2023.

## Files

- `index.html` — header, sidebar, and video grid
- `style.css` — dark theme and the narrow-screen layout
- `images/` — logo, menu, mic, create, notifications, and profile
- `SVG/` — sidebar and header icons

Open `index.html` in a browser. A small script toggles the sidebar. The search field and video cards are layout only: there is no player and no search results.
